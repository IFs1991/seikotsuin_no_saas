# 暫定プライバシー運用 — 2026-11-06

## 採用の根拠と範囲

事業者から、顧客向けの見積書・申込書・契約書は後日整備し、暫定原稿を採用して LP の法務ページへ早急に適用する指示を受けた。このメモは、その指示に基づき公開するプライバシーポリシーを運用するための手順を定める。

以下は今後の運用方針であり、過去の削除、現在の cleanup ジョブの稼働、バックアップの消去を実施・確認済みとする記録ではない。固定日数で全データを消去する保証や、新たな自動削除機能は設けない。外部監査や顧客向け契約書の完成を、この公開の前提に追加しない。

責任者・窓口担当は事業者。受付は `/contact?intent=privacy` の Google フォームまたは同ページ掲載の業務用メールを使う。受信・返信の運用は事業者から完了申告済みである。

## 受付から完了まで

1. **受付を記録する。** 受付日、対象製品、請求の種類、返信先、対象の組織・店舗、対象期間または操作 ID を記録する。患者情報の原文、認証情報、本人確認資料を GitHub issue や公開リポジトリへ記載しない。
2. **本人・権限・対象を確認する。** 登録済みの連絡手段等で本人と管理権限を確認する。OS の患者情報は利用院と連携する。個人からの請求を根拠に組織全体の情報を消去・開示しない。追加確認資料は必要最小限にする。
3. **処理範囲と残す理由を特定する。** アカウント、本文、素材と配信用コピー、外部連携の秘密、実行・承認・監査記録、問い合わせ・メール、契約・会計記録を分ける。返却の要否、未処理の業務・精算、法令上の保存、紛争・調査中の記録を確認する。サービス基盤のバックアップと利用者が接続した外部サービスの記録も分ける。
4. **対応方法と時期を知らせる。** 当事業者が処理する対象、返却や削除の方法、完了の見込み、残す対象と理由、外部サービスで必要な操作を依頼者へ案内する。法令上必要な対応は遅滞なく行う。調査で見込みが変わる場合は更新して知らせる。一律の「24 時間以内」「7 日以内」「30 日以内」の全消去を約束しない。
5. **対象を限定して処理し、結果を確かめる。** 対象製品の既存の管理機能・保守処理を使う。返却が必要な場合は権限を確認した安全な方法を使う。データベース、ファイル、配信用コピー等の処理結果を個別に確認する。連携解除、資格情報の失効、保存データの削除は別々に確認する。既存の監査保全、RLS、テナント境界を無効化しない。削除できない記録は、法令と当該請求に応じた利用停止・アクセス制限等の措置、残す理由と対応を記録する。
6. **結果を知らせ、残件を追跡する。** 完了した範囲、残る範囲、理由、次の対応と担当を記録して依頼者へ知らせる。バックアップまで消去した証拠がなければ全消去と表現しない。未完了の対象は完了・終了条件を確認するまで管理する。通常データを復元する際は、既存の削除・利用停止依頼を照合して反映する。

## 保存の見直し

利用終了、返却・精算の完了、問い合わせの完了、調査の終了、および削除請求を、保存の要否を見直す契機とする。運用担当は未完了の請求と保有継続の理由を定期的に確認し、利用目的が終了して保持する必要がなくなった情報を順次消去する。公開本文の期間はこれらの終了条件で定め、未検証の自動削除日数を転記しない。

Works の 24 時間・7 日の期限は、情報の種類によって参照失効・本文の削除対象化・素材の延長保持など意味が異なる。cleanup 関数が存在しても、実行フラグ、定期実行、Storage の削除成功、メタデータ・別コピー・バックアップの消去までは証明しない。期限だけをもって請求を完了扱いにしない。

## 根拠と実装上の境界

- [データ取扱いの実装照合](works-submission-data-evidence-20261101.md)：Works のアカウント、投稿案、素材、実行・監査、外部送信の各経路。最新限定照合の Works SHA は `8bd85a5c265da77a0a38d030538496610a0019d8`。
- [データ分類別の証拠](issue-167-data-evidence.md)：OS と Works の区分。OS の患者・予約情報に Works の一時データの期限を適用しない。
- [OpenAI Plugin guidelines](https://developers.openai.com/plugins/plugin-guidelines)：公開ポリシーに情報の分類、目的、受信者、保存期間、利用者の管理手段を記載し、ポリシーに従う。統一の保存日数や自動削除方式は指定されていない。イベントに基づく期間の開示が個別審査で承認されることまでは保証しない。
- [個人情報保護委員会・通則編](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)：3-4-1 の不要な情報の消去、3-8 の開示・訂正・利用停止等の請求への対応を参照。

共同利用、個人データの販売、全処理の国内完結、外部事業者を含めた一律の保存日数について、根拠のない有無や保証は追加しない。
