# Tiramisu Works LP Release Note

A separate Tiramisu Works landing page is now available at `/works`. The existing root landing page remains dedicated to Tiramisu OS for multi-store headquarters management. Visitors can move between the products through a small product-family router and explicit header/footer links.

Deployment requires reviewing `NEXT_PUBLIC_WORKS_FORM_URL`. When it is not configured, Works inquiry buttons use the existing public LP form URL.
